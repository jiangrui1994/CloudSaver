# 常见问题

部署与使用中的高频问题。外部搜索源相关的排错见[功能专题的 FAQ 章节](/guide/features/external-source#常见问题)。

## 镜像与拉取

### 应该拉哪个镜像？有几个版本？

| 镜像 | 说明 |
| --- | --- |
| `jiangrui1994/cloudsaver` | 正式版（Docker Hub） |
| `jiangrui1994/cloudsaver:test` | 体验版，最新功能先行（Docker Hub） |
| `ghcr.io/jiangrui1994/cloudsaver` | 正式版（GHCR，国内拉取通常更稳） |
| `ghcr.io/jiangrui1994/cloudsaver:test` | 体验版（GHCR） |

### 拉取镜像很慢怎么办？

推荐用 [DockerTarBuilder](https://github.com/wukongdaily/DockerTarBuilder) 在 GitHub Actions 上构建镜像压缩包，下载后导入 NAS 等设备：

1. Fork 该项目到自己仓库
2. 进入自己仓库的 Actions，选择设备平台类型对应的 workflow（如 `x86-64 pull and save docker image`）
3. 填入镜像名称（如 `ghcr.io/jiangrui1994/cloudsaver`）运行
4. 等待完成，下载生成的压缩包，`docker load` 导入即可

## 部署与访问

### 部署后访问不了？

1. 端口：项目默认只暴露 **8008** 一个端口，浏览器访问 `http://<服务器IP>:8008`；本地已占用可在端口映射处换成未占用端口
2. 云服务器需在安全组放行对应端口
3. 查看日志：`docker logs -f cloud-saver`
4. 重启 / 升级后出现 **Bad Gateway**：后端服务启动需要 1-2 分钟，请耐心等待后端就绪后再操作页面

### 文件挂载是必须的吗？

强烈建议。项目数据库（用户与配置信息）在 `/app/data`，配置在 `/app/config`；挂载后升级或重建容器不会丢数据、无需重新注册配置。详见[升级与数据持久化](/guide/upgrade)。

### 升级有什么注意事项？

1. 映射目录不变的情况下升级不丢数据
2. 重新创建容器时若映射目录指向同一目录，**务必先停止旧容器**，防止意外问题
3. 升级后后端启动需要时间，出现 Bad Gateway 请等待

## 注册与账号

### 注册为什么要填注册码？是多少？

项目可能被部署到外网，开放注册有风险，因此设置了注册码机制：

- 普通用户注册码：`9527`（默认）——只能配置自己的 Cookie 等用户设置
- 管理员注册码：`230713`（默认）——可配置网络服务、搜索频道与注册码

两者均可在管理员设置中修改，也可用环境变量 `ADMIN_USER_CODE` 覆盖管理员码。

## 搜索问题

### 搜不到资源 / 搜索失败？

- **「未搜索到相关资源」**：最常见原因是代理地址未正确配置
- **「搜索失败，请重试」**：代理地址不对，或代理速度过慢导致超时
- 代理设置见下方"代理配置"；也可接入[外部搜索源](/guide/features/external-source)增强检索

### 为什么要设置代理？如何设置？

频道抓取需要能访问 Telegram 的网络环境。可自行搜索关键词"**局域网代理共享**"了解如何把本机代理共享给局域网内的 CloudSaver 使用；在「系统设置」中填写代理地址即可。

带用户认证的代理服务器地址可按此格式填写：

```
username:password@192.168.1.1
```

### 明明看到有资源，为什么搜索不到？

TG 频道的搜索关键词匹配比较特殊，中文关键词经常搜不全。试试：

- 关键词前加 `#`，按**标签**搜索
- 点击**最新资源**直接浏览频道最新分享（不依赖搜索）
- 点击资源卡片上的标签可触发对应标签搜索

### 没有能访问 Telegram 的网络环境，能用吗？

可以：在「系统设置」配置代理让频道抓取走代理；或完全不用 TG 频道，通过[外部搜索源](/guide/features/external-source)接入本地 / 内网运行的 pansou，把 CloudSaver 用作纯内网的资源搜索 + 一键转存站。

## Cookie 与转存

### 怎么获取网盘 Cookie？

- **115**：使用油猴脚本 [115不大助手](https://greasyfork.org/zh-CN/scripts/474231-115%E4%B8%8D%E5%A4%A7%E5%8A%A9%E6%89%8B-full) 获取（建议获取微信/支付宝小程序端 Cookie，不易被挤掉）。注意：**alist 扫码获取的 115 Cookie 无法使用**
- **夸克**：参考 [alist 的夸克 Cookie 获取教程](https://alist.nn.ci/zh/guide/drivers/quark.html#cookie)

### 转存显示失败？

1. Cookie 可能已失效，重新获取并保存
2. 资源可能已被删除，点击资源标题跳转原始页面确认是否有效

### 天翼转存失败？

1. 先确认资源是否有效
2. 检查天翼云盘 App 设置中的**「设备锁」是否关闭**——部分账号需到网页版接收验证码关闭

## 使用技巧

- 点击搜索结果的**频道名**可跳转 TG 频道页
- 点击**标签**触发标签搜索（关键词搜索不好用时，试试关键词前加 `#`）
- 点击热门榜单**海报**触发关键词搜索，点击**标题**跳转豆瓣详情页
- 搜索框直接粘贴**网盘链接**回车即可解析并转存（没有代理环境也能用）
- 点击资源的**图片或详情**弹出资源详情（更多介绍）
- 点击**标题**复制资源链接（多条链接默认复制第一条；也有复制 ED2K / 磁力的独立入口）
- **长按标题**可选择关键词跳转豆瓣搜索

## PWA 与反向代理

### PWA 安装失败（移动端 Chrome）？

0.9.3 已修复安装清单问题；请确认镜像 ≥ 0.9.3，并通过 HTTPS 或 localhost 访问（PWA 要求安全上下文）。

### 反向代理注意事项

容器内置 Nginx 已处理好前后端拼装，通常只需代理 8008 一个端口；通过 HTTPS 域名访问时 PWA 与剪贴板等能力才完整可用。

## 安全相关

### 有没有在线 Demo 可以试用？

**没有，也绝不会有。** 本项目涉及网盘 Cookie 等敏感凭据，任何声称与本项目相关的在线网站均为未授权第三方搭建，存在窃取凭据的高风险——Cookie 等同于账号密码，请勿托付给陌生人。唯一可信的方式是自行私有化部署。

完整的合规与免责说明见[安全与使用声明](/about#安全与使用声明)。

### 安全建议

- 务必自行私有化部署，不建议使用来源不明的第三方在线站点
- 妥善保管网盘 Cookie 等敏感凭据的访问入口
- 公网部署建议：设置强 `JWT_SECRET`、开启注册管控、按需配置出站白名单 `PLUGIN_ALLOWED_HOSTS`
