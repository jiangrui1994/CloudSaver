# 项目介绍

CloudSaver 是一个**私有化部署的网盘资源订阅与转存工具**：聚焦于 Telegram 资源频道的订阅与发现，配合一键网盘转存、豆瓣联动与下游自动化推送，提供简单顺畅的资源发现与收集体验。

## 项目定位

在很多使用场景中，找资源并不一定是从一个特定的关键词开始搜索。对于作者而言，CloudSaver 的核心定位是一个「**资源发现与转存工具**」：

- **杂志式的频道订阅浏览**：Telegram 频道中有大量活跃分享者精心整理的**海报墙与图文详情**，闲暇时翻阅最新更新，像逛杂志一样随心发现感兴趣的内容。
- **长按选词搜豆瓣**：面对频道复杂的资源标题，**长按标题自由选取片名关键词**，一键跳转豆瓣搜索页面查看真实评分与影评口碑，先看评价再决定是否转存。
- **一键快捷转存**：遇到满意的资源，直接一键转存至夸克、115、天翼、123 网盘（目前支持这 4 款网盘一键转存，其他网盘支持链接解析与跳转），并支持选择与管理目标目录。
- **自动化推送联动**：转存完成后自动触发后续动作（如下载器自动追更、网盘同步脚本、消息通知等），打造顺畅的个人资源收集工作流。

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 频道订阅 | 搜索频道管理（增删/排序/启停/批量导入/有效性检测）、海报墙与最新资源流 |
| 资源搜索 | 关键词搜索、标签搜索、网盘链接直接解析转存、[外部搜索源](/guide/features/external-source)扩展 |
| 网盘转存 | 夸克 / 115 / 天翼 / 123 一键转存，目录选择与文件夹管理 |
| 推送联动 | 自定义推送（转存后 / 单独执行）+ 推送流编排，对接自动追更、网盘同步等生态 |
| 豆瓣 | 热门榜单聚合、个性化推荐、想看清单，海报直达搜索 |
| 多端 | PC + 移动端响应式界面，支持 PWA 安装 |

## 工作原理

[![CloudSaver 工作原理：搜索入口 → 处理与展示 → 生态联动](/diagrams/cloudsaver-workflow.png)](/diagrams/cloudsaver-workflow.png)

::: details 查看文字版流程
1. **内容来源**：TG 频道订阅、粘贴网盘链接、扩展外部源。
2. **处理与展示**：统一结果呈现，识别网盘链接、提取磁力 / ED2K，联动豆瓣评分与口碑详情。
3. **生态联动**：一键转存到网盘，转存后触发推送，联动自动追更与同步。
:::

外部搜索源在底层被抽象为虚拟频道，因此频道搜索已有的渐进加载、分组展开、复制转存等能力全部自动适用。
