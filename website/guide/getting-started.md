# 开始使用

部署完成并访问 `http://<服务器IP>:8008` 后，按下面五步完成首次配置，五分钟即可开始搜索与转存。

[![CloudSaver 首次使用路线图：注册管理员账号 → 按需配置代理 → 添加搜索源 → 配置网盘 Cookie → 搜索与转存](/diagrams/first-run-roadmap.webp)](/diagrams/first-run-roadmap.png)

代理按 TG 网络条件配置；TG 频道与外部搜索源可二选一或同时使用，网盘 Cookie 在需要转存时填写。点击图片可查看高清原图。

## 第一步：注册管理员账号

- 使用**管理员邀请码**注册（默认 `230713`；普通用户码为 `9527`，差别见 [常见问题](/guide/faq#注册与账号)）
- 管理员才能配置网络代理、搜索频道与外部搜索源等全局设置

## 第二步：（按需）配置代理

TG 频道抓取需要能访问 Telegram 的网络环境。在「**系统设置**」中填写局域网内可用的代理地址（HTTP / SOCKS5），保存后可用频道管理页的「网络检测」分步验证代理、公共网络与 t.me 的连通性。

没有代理环境？可以跳过这步直接走[外部搜索源](/guide/features/external-source)路线（第三步二选一）。

## 第三步：添加搜索源（二选一或全要）

**A. 添加 TG 搜索频道**

进入「配置管理 → 搜索频道」，添加公开频道（id 即 `t.me/xxxx` 的最后一段），或直接[批量导入社区整理的 125 个频道](/guide/features/search-channels#批量导入频道列表)。

![搜索频道管理：排序 / 启停 / 检测 / 批量导入](/screenshots/search-channels.png)

**B. 接入外部搜索源（推荐）**

部署 [pansou](https://github.com/fish2018/pansou) 后在「配置管理 → 外部搜索源」套用预置模板，改个地址即可拥有丰富的插件搜索源，不需要 TG 网络环境。完整教程见[外部搜索源专题](/guide/features/external-source)。

![外部搜索源管理列表](/screenshots/external-source-list.png)

## 第四步：配置网盘 Cookie（转存需要）

想一键转存，需要对应网盘的 Cookie（在「系统设置」中保存）：

- **115**：油猴脚本"115不大助手"获取（alist 扫码的不可用）
- **夸克**：参考 alist 的夸克 Cookie 教程

详细获取方法见 [常见问题 · Cookie 与转存](/guide/faq#cookie-与转存)。

## 第五步：搜索 → 转存 → 联动

1. 输入关键词搜索（或点「最新资源」浏览频道最新分享；关键词前加 `#` 可按标签搜索）
2. 点击资源卡片操作区的转存按钮，两步完成：选择资源 → 选择保存目录
3. （可选）到「扩展中心」配置[自定义推送](/guide/features/push-plugins)：转存完成自动触发追更任务、网盘同步或消息通知
