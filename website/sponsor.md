# 赞赏支持

如果 CloudSaver 陪伴了你的日常找片与转存时光，为你节省了宝贵的时间，非常感谢你的喜爱与支持！

## 作者想说的话

很多朋友在使用 CloudSaver 一段时间后，经常会在交流群或者私信里问我：*“作者以后会不会推出收费版或者高级付费功能？”*

我想借这个页面非常真诚地和大家说一下我的想法：

### 为什么不想做收费版？

从第一行代码开始，CloudSaver 就是为了解决我自己的真实需求诞生的——我更喜欢在 Telegram 频道里像逛杂志一样翻看分享者精心整理的海报墙，长按选词去豆瓣看一眼真实口碑，觉得好再一键转存到网盘。

我一直坚持一个简单的理念：**做纯粹、干净、真正解决问题的个人自建工具**。我不想通过把核心功能加锁、搞各种付费墙或者商业推广来消耗大家的信任。能够看到自己写的工具切实帮到许多同好，这种纯粹的快乐和成就感远比搞商业化来得踏实。

### 只要 Tokens 能撑住，就会一直更新下去

项目日常的迭代维护、新功能开发（例如 v0.10.0 的外部搜索源引擎）以及大量前后端单元测试的编写，背后少不了借助各种 AI 工具协助思考架构与推演代码。在长期的开发与重构中，确实消耗了大量的模型 tokens 以及工作之余的个人精力。

但请大家放心：**只要 tokens 能撑住、精力和条件允许，CloudSaver 就会一直持续维护和迭代下去**。

除了赞赏之外，以下方式同样是对 CloudSaver 巨大的支持：

1. **Star 支持**：前往 [GitHub 仓库](https://github.com/jiangrui1994/CloudSaver) 点一颗免费的 **Star ⭐**，让更多人发现这个项目；

3. **反馈与共建**：在日常使用中发现任何问题或有好想法，欢迎在交流群交流或提交 GitHub Issue。
